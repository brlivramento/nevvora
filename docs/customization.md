# Personalização
Sobrescreva os tokens depois do CSS do framework:
```css
:root {
  --nv-accent: #718578;
  --nv-font: "Helvetica Neue", Helvetica, Arial, sans-serif;
  --nv-radius: 14px;
  --nv-bg: #fafbfc;
  --nv-surface: #fff;
  --nv-border: #e9ecf1;
  --nv-shadow: 0 3px 7px #28324803, 0 12px 32px #28324809;
}
```
Cores semânticas de status e algumas cores decorativas estão nos respectivos componentes. O tema incluído é claro.
