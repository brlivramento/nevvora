# Primeiros passos
Use `dist/nevvora.css`. O JavaScript é opcional.
```html
<article class="nv-card">
  <label class="nv-field">Nome<input class="nv-input"></label>
  <button class="nv-btn nv-btn--primary">Salvar</button>
</article>
```
A galeria abre diretamente por arquivo; módulos fonte JS usam scripts clássicos. O build concatena os componentes em ordem, sem transpilar ou minificar.
